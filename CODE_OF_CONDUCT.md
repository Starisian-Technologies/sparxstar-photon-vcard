# Code of Conduct

## Our Commitment

Starisian Technologies maintains **SPARXSTAR Photon VCard** as a proprietary, commercially licensed project. We are committed to maintaining a professional, respectful, and inclusive environment for all contributors, collaborators, and community members who interact with this project.

---

## Scope

This Code of Conduct applies to all project spaces managed by Starisian Technologies, including:

- GitHub repository (issues, pull requests, discussions, code review comments)
- Direct communications with the Starisian Technologies team regarding this project
- Any other channels officially associated with this project

---

## Standards

We expect all participants to:

- **Be respectful and professional** — Treat others with courtesy. Disagreements are handled constructively.
- **Be honest and accurate** — Report bugs and security issues truthfully and with sufficient detail.
- **Respect proprietary boundaries** — Do not attempt to redistribute, reverse-engineer, or misuse proprietary code or data obtained through access to this repository.
- **Protect privacy** — Do not include real user data, credentials, or personally identifiable information in issues, pull requests, or public communications.
- **Report security issues responsibly** — Follow the coordinated disclosure process described in [SECURITY.md](SECURITY.md). Do not disclose vulnerabilities publicly before a fix is available.

---

## Unacceptable Behaviour

The following behaviours are not tolerated:

- Harassment, intimidation, or discrimination in any form
- Publication of others' private information without consent
- Deliberate introduction of security vulnerabilities or malicious code
- Misrepresentation of identity or affiliation
- Violation of the [LICENSE.md](LICENSE.md) terms
- Attempts to circumvent access controls or licensing mechanisms

---

## Enforcement

Violations of this Code of Conduct should be reported to Starisian Technologies at **support@starisian.com**.

Reports are handled confidentially. Starisian Technologies reserves the right to remove contributions, revoke access, or take other appropriate action in response to violations, without prior notice.
