# Support

## Commercial support

SPARXSTAR Photon VCard is commercially maintained by Starisian Technologies.

- Primary support channel: `support@starisian.com`
- Security disclosures: follow [SECURITY.md](SECURITY.md) and do not open public vulnerability reports.

## Before contacting support

Include:

- plugin version
- WordPress version
- PHP version
- reproducible steps
- expected behavior
- actual behavior
- relevant logs (with secrets removed)

Do not include credentials, tokens, private keys, or production secrets.
